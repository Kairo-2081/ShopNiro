# Seller Payout Dispute

**Trigger:** A seller says an eligible payout is missing, short, late, duplicated, or sent to the wrong account. The admin payout owner coordinates with finance; support keeps the seller updated.

1. Verify the seller identity and capture the seller ID, payout request ID, amount, request date, and the seller's description. Do not request full bank credentials in chat or email.
2. Review the payout request, seller ledger, hold/available balance, verified payout-account status, and any recorded external payout reference in the admin tools. Earnings become eligible seven days after delivery; held funds are not withdrawable. Commission is 15% of delivered item subtotal; shipping is excluded.
3. Compare the ledger entries and request history with the bank/mobile-finance provider receipt using the external reference. Check for a rejected request (which returns funds to available balance), a pending request, a completed transfer, or a later refund/negative ledger entry.
4. Do not mark the request paid without a confirmed external transfer reference. Do not edit/delete ledger entries, create a second payout to “make it right,” or change payout-account verification as a shortcut. If the destination account changed, pause the request and verify the new account through the established seller-verification process; changing account details should clear prior verification.
5. If not yet sent, keep the disputed request unpaid while the admin owner investigates. If already sent to the wrong destination or duplicated, contact the payment provider/bank immediately and record the case/reference. Make any approved correction as a new auditable ledger/payout action, never by rewriting history.
6. Reply to the seller with the finding, amount/status, next owner, and next update time. Escalate suspected account takeover, ledger mismatch, or an unreferenced transfer to the production/admin owner.

**Close when:** The ledger and external transfer are reconciled, any correction is auditable and approved, and the seller has a written resolution. See [Seller and Rider Payout Policy](../payouts.md).
